# ARL SBU November Revenue Gap Assessment

Interactive dashboard tracking the **November 2026** revenue & collection performance of **Akij Resource Ltd. (ARL)** SBUs, plus the per-SBU gap-assessment submissions from brand custodians.

## Files

- `index.html` — the dashboard (fully self-contained, no build step)
- `AEL.png` — performance snapshot attached to the *Akij Essentials (Manufacturing)* submission

## Deploy

Static site — deploy as-is. The root file is `index.html`, served directly by Vercel (or any static host).
